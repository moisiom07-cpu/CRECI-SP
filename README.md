# Roadmap CRECI-SP – Assistente Administrativo

Checklist de estudos de 06/11 a 29/11/2026, com contagem regressiva, placar dos simulados e progresso salvo no próprio aparelho. Sem internet, sem cadastro, sem dependências.

## Arquivos

- `index.html`: o site inteiro (HTML, CSS e JavaScript juntos)
- `sw.js`: faz o site funcionar offline quando hospedado
- `manifest.webmanifest` e `icon.svg`: permitem instalar como app no celular

## Subir no GitHub Pages

1. Crie um repositório novo no GitHub (ex.: `roadmap-creci`), público.
2. Envie os 5 arquivos para a raiz do repositório (botão **Add file > Upload files**).
3. Vá em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
4. Em 1 ou 2 minutos o site abre em `https://SEU-USUARIO.github.io/roadmap-creci/`.

## Usar offline

- **No computador:** dê dois cliques no `index.html`. Funciona sem internet e o progresso fica salvo.
- **No celular (recomendado):** abra o link do GitHub Pages uma vez com internet e use **Adicionar à tela inicial** (Chrome/Android) ou **Compartilhar > Adicionar à Tela de Início** (iPhone). Depois disso abre offline como um app.

## Observações

- O progresso fica salvo no navegador de cada aparelho. Computador e celular não sincronizam entre si.
- Limpar os dados do navegador apaga o progresso.
- Para mudar tarefas ou datas, edite a lista `DAYS` dentro do `index.html`.
- Confirme a data da prova (29/11/2026) e o local no edital oficial e no cartão de confirmação.
